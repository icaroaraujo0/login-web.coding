Tela de Autenticação — Aura

Este projeto consiste em uma interface web responsiva e moderna para autenticação de usuários (tela de login), desenvolvida com tecnologias fundamentais da web (HTML5 e CSS3). O objetivo principal é fornecer uma experiência de usuário (UX) fluida, acessível e visualmente agradável.

🛠️ Tecnologias Utilizadas

HTML5: Estruturação semântica do formulário e dos elementos da página.

CSS3: Estilização, layout flexível (Flexbox), efeitos visuais (sombras e arredondamento) e animações (@keyframes).

✨ Funcionalidades e Características

Design Responsivo: Adaptação do layout para diferentes tamanhos de tela (dispositivos móveis e desktops) utilizando Media Queries.

Feedback Visual: Efeitos de interatividade (hover e active) nos botões e campos interativos.

Animações de Entrada: Utilização de keyframes para renderização suave dos elementos ao carregar a página.

Layout Centralizado: Organização em cards flutuantes com sombras suaves para melhor hierarquia visual.
